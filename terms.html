Conditions Générales d'Utilisation

Bienvenue sur PerfLog (« l'application », « le service »). Les présentes CGU régissent votre utilisation de l'application mobile PerfLog développée par Vincent BERHOUET. En téléchargeant, installant ou utilisant l'application, vous acceptez d'être lié par ces CGU.

1. Description du service

PerfLog est une application mobile de suivi d'entraînement de musculation, permettant à l'utilisateur de :

  • Consulter un catalogue d'exercices curé (≈ 400 exercices)
  • Créer des programmes d'entraînement personnalisés
  • Enregistrer ses séances, séries, répétitions et charges
  • Visualiser ses progrès via des statistiques (PRs, tonnage, fréquence)
  • Sauvegarder ses données dans un cloud chiffré end-to-end (optionnel, opt-in)
  • Restaurer ses données sur un autre appareil

L'application est disponible sur iOS et Android.

2. Compte utilisateur

2.1 Mode local

Par défaut, l'utilisation de PerfLog ne nécessite aucun compte ni inscription. Toutes les données restent localement sur votre appareil, chiffrées par les mécanismes système (Data Protection iOS, Keystore Android).

2.2 Mode cloud (opt-in)

Si vous activez la fonctionnalité Sauvegarde Cloud, vous devez :

  • Fournir une adresse email valide (utilisée pour authentification OTP)
  • Définir une passphrase forte (≥ 12 caractères) que vous seul connaissez
  • Conserver votre code de récupération à 12 mots (générés selon BIP-39)

Important : nous n'avons aucun accès à votre passphrase ni à votre code de récupération. Si vous les perdez, vos données chiffrées sont irrécupérables (architecture E2E). C'est le prix de la confidentialité.

2.3 Sécurité du compte

Vous êtes responsable de :

  • La confidentialité de votre passphrase
  • La conservation de votre code de récupération (papier, gestionnaire de mots de passe, etc.)
  • L'accès à votre boîte email (utilisée pour les codes de connexion OTP)

3. Utilisation acceptable

Vous vous engagez à :

  • Utiliser l'application à des fins personnelles et non commerciales
  • Ne pas tenter de contourner les mécanismes de sécurité (cert pinning, chiffrement)
  • Ne pas utiliser l'application pour stocker des données illégales

Nous nous réservons le droit de suspendre tout compte cloud abusant manifestement du service (DoS, tentatives d'intrusion sur les API).

4.3 Vos données

Vous restez seul propriétaire des données que vous saisissez (programmes, séances, mesures). Aucune cession ne nous est faite. À tout moment, vous pouvez :

  • Exporter vos données au format JSON (Profil → Exporter)
  • Supprimer vos données (Paramètres → Supprimer toutes les données)
  • Supprimer votre compte cloud si activé (RGPD Art. 17)

5. Limitations de responsabilité

5.1 Conseil médical

PerfLog n'est pas un conseil médical. Les descriptions d'exercices sont à titre informatif. Consultez un professionnel de santé avant tout programme d'entraînement, notamment en cas de problème articulaire, cardiaque ou musculo-squelettique.

Nous déclinons toute responsabilité pour blessure résultant de l'utilisation des exercices proposés sans accompagnement professionnel.

5.2 Disponibilité

L'application est fournie « telle quelle » sans garantie de fonctionnement ininterrompu. Les services cloud peuvent connaître des indisponibilités temporaires (maintenance Supabase, OVH, etc.).

5.3 Perte de données

Bien que tout soit fait pour préserver vos données :

  • En mode local, une perte/réinitialisation de l'appareil sans backup cloud activé entraînera une perte définitive des données
  • En mode cloud, l'oubli combiné de votre passphrase ET de votre code de récupération rendra vos sauvegardes irrécupérables (architecture E2E sans backdoor)

Nous recommandons fortement :

  • Activer la sauvegarde cloud si vous tenez à vos données
  • Stocker votre code de récupération en lieu sûr (papier dans coffre, 1Password, etc.)
  • Effectuer des exports JSON réguliers en complément

7. Suppression de compte et de données

7.1 Suppression locale

Paramètres → Données → Supprimer toutes les données.

Effet : effacement immédiat et irréversible de la base locale + clé de chiffrement.

7.2 Suppression compte cloud

Paramètres → Sauvegarde cloud → Supprimer mon compte.

Effet : suppression sous 30 jours (période de grâce pour annulation), puis purge effective avec audit RGPD Art. 30 (hash SHA-256 conservé 30 jours pour traçabilité légale).

7.3 Inactivité prolongée

Les comptes cloud inactifs depuis 24 mois sont automatiquement marqués pour suppression avec 30 jours de préavis (notification email). Vous pouvez prolonger via le bouton dédié dans Paramètres.
